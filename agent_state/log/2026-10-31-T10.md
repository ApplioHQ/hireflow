**Cookies** are small text files a website stores on your browser to remember things about you across visits.

| Purpose | Example |
|---------|---------|
| **Session** | Keep you logged in (session ID) |
| **Preferences** | Remember theme, language, consent |
| **Tracking** | Analytics, ads, cross-site profiling |
| **Security** | CSRF tokens, fraud detection |

**Key attributes:** `name`, `value`, `domain`, `path`, `expires`/`max-age`, `Secure` (HTTPS only), `HttpOnly` (blocks JS access), `SameSite` (controls cross-site sending).

**Two types:**
- **First-party** — set by the site you're on
- **Third-party** — set by embedded trackers/ads (being phased out)

**TL;DR:** Cookies = browser memory for websites. Session cookies die when you close the tab; persistent ones last until expiry.
