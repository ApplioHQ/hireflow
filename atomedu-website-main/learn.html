Learn how Proof Lab works

Start with a problem you know, follow the steps, then try writing your own. Proof Lab checks supported math with rules, not a conversational guess.

Start here

A simple path through a problem

These are actions you can take in Proof Lab now.

Enter the math

Type an equation or use the pad to insert a fraction, root, power, or other visual template.

Solve

Run a supported problem and read the result, restrictions, and line-by-line reasoning.

Check work

Submit your own sequence of steps. See which transitions the engine verifies and where it finds an error.

Ghost steps

When you skip a valid intermediate move, translucent reconstructed steps show the missing bridge.

Generate

Choose a topic, difficulty, and optional seed to make a new practice problem.

Graph

Pan, zoom, and compare functions visually. Graphs are numerical aids, not verified proofs.

In practice

How you would use it

Suppose you need to solve 2x + 3 = 7. Enter it in Solve and follow how each side changes. Then switch to Check work, write your own checkpoints, and see whether the transitions hold up. If you skipped a valid move, Ghost steps can make it visible without pretending you wrote it. Generate a similar problem and try again.

Proof Lab is strongest when the problem matches a supported rule family. Use the coverage list in the tool to see what it can verify; unsupported problems are not silently promoted to proofs.
