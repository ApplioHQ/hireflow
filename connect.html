Use Applio inside Claude & ChatGPT

Add Applio as a connector and your AI can search live jobs, score your resume against any posting, pull the keywords that matter, and tailor your resume, without leaving the chat. Free to add.

Add it in 30 seconds

Claude

  1. Open Settings → Connectors (on claude.ai or the desktop app).
  2. Click Add custom connector.
  3. Name it Applio and paste the URL above.
  4. Save, then enable Applio in any chat from the tools menu.

ChatGPT

  1. Open Settings → Connectors (requires a plan that supports custom MCP connectors; turn on developer mode if needed).
  2. Click Add / New connector.
  3. Paste the URL above and set authentication to None.
  4. Save, then pick Applio's tools in a chat.

Any MCP client works too (Claude Desktop, Cursor, and others), it is a standard Streamable-HTTP MCP server.
