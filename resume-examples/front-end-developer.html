Frequently asked questions

What should a front-end developer resume include?

Lead with shipped projects and metrics (performance, conversion), name your framework stack, and show accessibility and testing experience.

Should I list a portfolio?

Yes. Link a portfolio or GitHub prominently, front-end work is best judged by seeing it.

React or framework-specific?

Match the posting. If it names React, Vue, or Angular, lead with that framework and show depth.
